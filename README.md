## Про проєкт

**Portfolio Site Template** — універсальний шаблон односторінкового персонального портфоліо для розробників, аналітиків та інших IT-фахівців.

Ідея проєкту — створити простий адаптивний сайт-портфоліо, який можна легко налаштувати під себе: змінити тексти, навички, проєкти, досвід роботи та контактну інформацію без необхідності змінювати основну структуру застосунку.

Проєкт розробляється на Angular. На першому етапі реалізується frontend без backend-частини.

## Поточний функціонал

На цей момент реалізовано:

- Односторінкову структуру з навігацією між розділами:
  - Hero
  - About
  - Skills
  - Projects
  - Experience
  - Contacts
  - Footer
- Перемикання мов: українська та англійська.
- Винесення демонстраційного контенту в окремий файл конфігурації для спрощення налаштування шаблону.
- Розділення застосунку на Angular-компоненти.
- Базове адаптивне оформлення сторінки.

Усі персональні дані та приклади контенту в шаблоні є демонстраційними й призначені для заміни.

## About the Project

**Portfolio Site Template** is a universal one-page personal portfolio template for developers, analysts, and other IT professionals.

The goal is to create a simple, responsive portfolio website that can be easily customized: users can replace the text, skills, projects, work experience, and contact information without changing the application's core structure.

The project is built with Angular. The first stage focuses on the frontend, without a backend.

## Current Features

The current implementation includes:

- A one-page layout with section navigation:
  - Hero
  - About
  - Skills
  - Projects
  - Experience
  - Contacts
  - Footer
- Ukrainian and English language switching.
- Demo content stored in a separate configuration file for easier customization.
- Application structure organized into Angular components.
- Basic responsive styling.

All personal details and content examples are placeholders intended to be replaced.

## Technologies

## Roadmap

Planned improvements:

- Add a reusable back-to-top component.
- Add configurable contact options: hide the email address or use a button to open an email application.
- Add downloadable PDF resumes in Ukrainian and English.
- Improve responsive design and visual styling.
- Explore website analytics integration.
- Consider adding backend functionality if needed.
